# V2 MLX Model Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the v2 SML model usable with MLX while preserving the current PyTorch implementation and model specifications.

**Architecture:** Add a parallel `sml_mlx.py` module that reuses `SMLConfig`, `GenerationConfig`, and YaRN helpers from `sml.py`. The MLX model mirrors the existing block layout, RoPE/YaRN cache, grouped-query attention, KV-cache decoding, tied embeddings, loss helper, and generation controls without changing the current PyTorch import path.

**Tech Stack:** Python 3.12, MLX (`mlx.core`, `mlx.nn`), pytest, existing v2 SML config.
